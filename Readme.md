# ZebraEURedSetupBT Application

This application will setup the classic bluetooth to discoverable on factory stock EU RED Zenbra ZD230 Printers.

Scan the Bluetooth mac address and send the script to printer.

Translated in English, French, Italian, Spanish, Portuguese, German,... check the source for current state of translations.
